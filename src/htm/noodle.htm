Noodle is a drawing program.

Noodle is a 1-bit illustration program for Varvara, written in Uxntal. It features an invaluable cleanup brush that gets rid of the annoying sharp edges in pixelart lineworks and a collection of halftone patterns.

Noodle exports to the icn format, and can import uncompressed grayscale tga images. It is currently used in the creation of various monochromatic illustration projects such as the Neauismetica.
